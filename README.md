# aurora-support-agent

Customer-facing AI agent that answers shipment questions and can delegate
routing/ETA questions to `aurora-routing-agent` via A2A, for **Aurora
Logistics** (fictitious company used as a Backstage reference example).

Mockup only — no real agent runtime, just an Agent Card and
`catalog-info.yaml` to demonstrate Backstage cataloging agent-to-agent
orchestration.

- Owner: `team-ai-agents`
- System: `customer-experience`
- Agent Card: [`.well-known/agent.json`](./.well-known/agent.json)
